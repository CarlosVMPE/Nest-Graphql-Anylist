# Dev

1. Clonar el proyecto
2. Copiar el ```env.template``` y renombrar a ```.env```
3. Ejecutar
```
npm install
```
4. Levantar la imagen (Docker desktop debe estar ejecutandose)
```
docker-compose up -d
```
5. Levantar el backend de Nest
```
npm run start:dev
```

6. Visitar el sitio
```
localhost:3000/graphql
```
